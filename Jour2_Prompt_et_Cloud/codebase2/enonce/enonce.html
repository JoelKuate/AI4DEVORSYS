Formation GitHub Copilot dans VS Code : Énoncé participant

0 / 100 étapes réalisées · Durée indicative : 7 h

Comment travailler

Cette formation vous fait construire l'environnement Copilot complet autour d'une seule base de code : code/, une petite application de liste de tâches. Chaque module suit la même logique :

  • Pourquoi : ce que la fonctionnalité résout, et quand l'utiliser.
  • Commande ou raccourci : ce que vous tapez ou cliquez.
  • Travail à faire : l'exercice, toujours appliqué aux fichiers de code/.
  • Résultat attendu : ce que vous devez obtenir pour valider l'étape.

Notez vos observations dans la zone de texte, cochez « Fait », et passez à l'étape suivante. Votre progression est enregistrée dans ce navigateur ; l'export produit un fichier .txt.

Remarque : les raccourcis sont donnés pour Windows. Les menus, noms de fichiers de configuration et commandes CLI évoluent selon les versions de VS Code et de Copilot. En cas d'écart, vérifiez dans la palette de commandes (Ctrl+Shift+P, taper « Copilot ») et dans la documentation officielle GitHub Copilot.

Aide-mémoire : où vit chaque élément de Copilot

  • .github/copilot-instructions.md : instructions globales du dépôt
  • .github/instructions/*.instructions.md : instructions ciblées par type de fichier (applyTo)
  • AGENTS.md : instructions lues par les agents, à la racine
  • .github/prompts/*.prompt.md : prompts réutilisables, appelés avec /nom
  • .github/agents/*.agent.md : agents personnalisés (rôle, outils, modèle)
  • .github/skills/<nom>/SKILL.md : compétences réutilisables
  • .vscode/mcp.json : serveurs MCP (outils externes)

Chat : /explain /fix /tests /doc /clear /help · Participants : @workspace @terminal @vscode @github · Variables : #file #selection #codebase #editor #problems #fetch #terminalLastCommand

Clavier (Windows) : Tab accepter · Esc rejeter · Ctrl+Droite mot par mot · Alt+] / Alt+[ alternatives · Ctrl+Entrée panneau de complétions · Ctrl+Alt+I chat · Ctrl+I chat inline
